# MyCampusView — WhatsApp outreach scripts

Tone: short, respectful, principal-friendly. No feature dumps. One ask per message.

---

## 1) Cold intro (warm city / CBSE school)

```
Namaste {{Name}} ji,

I’m {{YourName}} from MyCampusView — a school operations system
(fees, attendance, admissions, parent updates) used by schools
that want less Excel + WhatsApp chasing.

Would you have 15 minutes this week for a quick screen-share demo?
Happy to focus only on fees / attendance — whichever is the bigger pain.

— {{YourName}}
contact@mycampusview.com
```

---

## 2) After a referral

```
Namaste {{Name}} ji,

{{ReferrerName}} suggested I reach out — they thought MyCampusView
might help {{SchoolName}} with fee follow-ups and parent communication.

I can show a 15-min live demo (fee dashboard + parent view).
Tue or Thu afternoon work for you?

— {{YourName}}
```

---

## 3) Follow-up (no reply after 4–5 days)

```
Hi {{Name}} ji — quick follow-up.

Many principals ask us first about unpaid fees and parent complaints.
Happy to show only that slice in 15 minutes — no long presentation.

If timing is bad, tell me a better week and I’ll check back.
```

---

## 4) After demo — send annex + next step

```
Thank you for the time today, {{Name}} ji.

As discussed, sharing:
1) Feature & pricing annex (PDF)
2) Suggested pack: {{Essential / Starter / Growth / Elite}}

Next step: confirm student count + academic year start,
and we’ll send a formal quotation (ref format MCV/Q/…).

Any questions from accounts/IT — happy to join a short call.
```

---

## 5) Pilot close

```
{{Name}} ji — proposal for a clean start:

• {{Pack}} pack + setup
• Go-live focus: Fees + Parents (or Attendance)
• 30–45 day pilot on live data, then expand modules

If this works, we lock the quote this week and schedule onboarding.
Shall I send the final quotation today?
```

---

## Tips

- Send **Tue–Thu, 10:30–12:30 or 16:00–18:00 IST**
- Personalise with school board / known pain (fees, TC delay, attendance)
- After “yes to demo”, send calendar link or 2 concrete slots only
- Attach annex PDF only after interest — not in the first cold message
