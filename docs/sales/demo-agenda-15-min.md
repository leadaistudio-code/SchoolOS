# MyCampusView — 15-minute demo agenda

Goal: one clear pain → one “aha” → next step (annex + quote).  
Not a full product tour.

**Ideal attendees:** Principal / Vice Principal + accountant (or office admin).

---

## Minute 0–2 — Open

- Confirm time box: “We’ll finish in 15 minutes.”
- Ask **one** question:
  - “What’s harder right now — **fee collection**, **attendance**, or **parent updates**?”
- Mirror their answer; ignore other modules for this call.

---

## Minute 2–8 — Live “aha” (pick one path)

### Path A — Fees (default)

Show only:
1. Student fee ledger (what’s due / overdue)
2. One click reminder / collection view
3. Simple report: unpaid by class

**Line to use:** “This is the spreadsheet your office runs every evening — live.”

### Path B — Attendance

Show only:
1. Class mark / biometric-linked status (if relevant)
2. Parent visibility of absent today
3. Monthly summary for one class

### Path C — Admissions

Show only:
1. Enquiry → application pipeline
2. One status change + what office sees next

---

## Minute 8–11 — Parent + trust

- Parent view: fee / notice / attendance (30–60 seconds)
- One line on data safety: school-wise isolation, roles, no shared login mess
- Do **not** deep-dive infra unless they ask

---

## Minute 11–13 — Fit + pack

- “Based on ~{{N}} students, most schools start on **{{Growth / Starter}}**.”
- Mention setup once (₹15,000) + GST extra — calmly, no apology
- Offer pilot: fees (or attendance) live in 30–45 days, then expand

---

## Minute 13–15 — Close

Ask for:
1. Student count (approx)
2. Current tools (Excel / other ERP / nothing)
3. Decision timeline (this month / next term)

**Next step script:**
> “I’ll send the feature annex PDF today and a draft quotation
> (MCV/Q/…). If accounts needs a call, we’ll do 20 minutes with them.”

Send annex within **2 hours** of the demo.

---

## Do / Don’t

| Do | Don’t |
| --- | --- |
| Use their school name on screen if possible | Open 12 modules |
| Let them click once | Read every feature bullet |
| End with date for quote review | “Let us know whenever” |

---

## Objection cheat sheet

| They say | You say |
| --- | --- |
| “We already have software” | “Where does it still force Excel — fees or TC?” Demo that gap. |
| “Too expensive” | Show unpaid fee impact for 1 month vs pack cost. Offer Essential as start. |
| “Send brochure” | “Better: 15-min live on fees. Brochure won’t show your workflow.” |
| “After exams / next year” | Book a hold date + send annex now so trust can budget. |
