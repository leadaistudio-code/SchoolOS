```text
# Video 3: Data: features and labels

[00:00:00.000] (Intro) MyCampusView Academy. AI for Young Builders, video 3. Data: features and labels.
[00:00:10.600] An AI is only as good as the examples it learns from. So let us look closely at those examples: the data.
[00:00:20.900] Here is some data about fruit. Each row is one example. Colour, size and shape are features: clues we can measure. The fruit name is the label: the answer we want the AI to learn.
[00:00:37.800] Good features connect to the label. Colour is a great clue for apple or orange. Ear shape helps tell cats from dogs. But the date a photo was taken tells you nothing at all, so it is a useless feature.
[00:00:55.300] Watch out for this trap. If every dog photo shows a brown dog on grass, the AI might learn that a brown thing on grass means dog. Then it gets a white dog indoors completely wrong.
[00:01:11.200] So good data has three things. Lots of examples. Lots of variety: different colours, sizes, angles, lighting and backgrounds. And labels that are correct.
[00:01:27.200] (Outro) Let us recap. Data is a set of examples. Features are the clues; the label is the answer. More examples, and more variety, make better AI. Next: How computers see: pixels.
```
