# MyCampusView Tally Connector (Windows)

Official desktop app + Windows Service for schools that use Tally.ERP 9.

## What schools install

After you build, give the school:

`dist/MyCampusView-Tally-Connector-Setup-1.0.2.exe`

Product name shown in Windows: **MyCampusView Tally Connector**

## Branding

Official MyCampusView logo assets are generated by:

```powershell
npm run brand
```

That script:
- removes the solid black background (transparent PNG)
- crops the mark into a square `build/icon.png` + multi-size `build/icon.ico`
- writes `gui/logo-wide.png` for the in-app header

`npm run dist` runs this automatically via `predist`.

Output:

- `dist/MyCampusView-Tally-Connector-Setup-1.0.2.exe` â€” full installer (NSIS)
- Start Menu + Desktop shortcuts
- Per-machine install under `C:\Program Files\MyCampusView Tally Connector\`

## School setup (customer steps)

1. Install **MyCampusView Tally Connector** (approve UAC if prompted).
2. Open Tally.ERP 9 on the same PC and load the school company. Enable XML/HTTP on port **9000**.
3. In MyCampusView â†’ **Settings â†’ Tally ERP** â†’ generate a pairing code.
4. In the connector app:
   - Enter the school cloud URL
   - Paste the pairing code
   - Click **Pair with school**
   - Click **Test Tally**
   - Click **Install & start service** (Administrator prompt) for auto-start on boot

## Auto-start behaviour

| Mechanism | Purpose |
|---|---|
| Windows Service `MyCampusViewTallyConnector` | Starts at boot (even before login). Preferred for always-on office PCs. |
| Login item + tray app | Opens quietly at user sign-in; runs a background sync worker if the service is not running. |
